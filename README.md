تطبيق أندرويد متكامل وحديث لإدارة المستودعات والمخازن، نقاط البيع، دفاتر الفواتير الورقية المسطرة، حسابات العملاء والموردين، والطباعة الحرارية ومشاركة الإيصالات بدقة 4K عبر واتساب.

---

## 🌟 المميزات الرئيسية (Key Features)

### 1. 📦 المخزون والأصناف بنظام الأسطر المسطرة (Inventory Table)
- **عرض جدول مسطر كالفاتورة:** عرض عالي الكثافة لجميع الأصناف (الاسم، الباركود، الرصيد المتاح، تكلفة الشراء، سعر البيع، وإجراءات سريعة).
- **إدارة الوحدات متعددة المستويات:** دعم الكرتون، الشد، الباكت، والحبة مع حساب معامل التحويل التراكمي وتكلفة أصغر وحدة تلقائياً.
- **حساب تكلفة الشراء وهامش الربح:** ربط سعر شراء الكرتون باحتساب تكلفة الحبة، وحساب نسبة الربح فورياً.
- **حماية قيمة المخزون:** تسوية كمية المخزون مع الحفاظ على القيمة المالية عند تغيير معاملات التحويل.
- **تنبيهات نقص المخزون:** إشعار مرئي عند وصول الصنف للحد الأدنى.

### 2. 🧾 دفتر الفواتير الورقي والطباعة (Invoices & Thermal Printing)
- **تصميم دفتر محاسبي مسطر:** محاكاة الدفتر الورقي الكلاسيكي بخط أميري أنيق وتقسيمات مالية دقيقة.
- **إدخال فوري ذكي:** كتابة مباشرة في الحقول (الإجمالي، الكمية، والبحث) مع كيبورد رقمي وحساب تلقائي لسعر الواحدة.
- **اقتراحات ذكية:** التعرف السريع على الأصناف والعملاء والموردين فور الكتابة.
- **شراء الجملة والإضافة السريعة:** إضافة صنف جديد للمخزن مباشرة من داخل فاتورة الشراء مع إدخال عدد الحبات في الكرتون.
- **إيصالات 4K فائقة الدقة:** توليد فواتير رسومية بدقة 4K UHD لمشاركتها مباشرة عبر تطبيق واتساب أو حفظها كـ PNG / PDF.
- **طباعة حرارية ESC/POS:** دعم طابعات البلوتوث والشبكة (Wi-Fi/LAN IP) لمقاسات 58 مم و 80 مم مع صفحة اختبار طباعة فورية.

### 3. 👥 حسابات العملاء والموردين والعمليات (Accounts & Ledgers)
- **كشف حساب مسطر كالفاتورة:** عرض كافة عمليات وفواتير العميل أو المورد في جدول مسطر ومرتب حسب الأحدث.
- **إجراءات سريعة لكل سطر:** تعديل، مشاركة عبر واتساب، وطباعة لكل عملية أو فاتورة على حدة.
- **تحديد متعدد (Batch Actions):** تحديد عدة فواتير وسندات ومشاركتها مجمعة بنقرة واحدة.
- **سندات السداد والتسوية العكسية:** تسجيل وتعديل وحذف سندات السداد مع ارتداد الرصيد المالي وحركة المخزون بدقة تامة.

### 4. ⚙️ مركز الإعدادات المتقدم والنسخ الاحتياطي (Advanced Settings)
- **تبويبات مخصصة ومصغرة:** (المتجر والطابعة، النسخ والمزامنة، تشخيص النظام).
- **هوية المتجر والإيصال:** تخصيص اسم المتجر، النشاط، رقم الهاتف، والسياسة المطبوعة أسفل الفاتورة.
- **مزامنة سحابية ووضع محلي:** ربط حساب Google والمزامنة الفورية عبر Firebase Firestore، أو العمل محلياً دون إنترنت.
- **تصدير واستعادة شاملة:** تصدير نسخة احتياطية بصيغة JSON، استيراد النسخ مع تخطي التكرار، وتصدير تقرير جرد المخزون كملف PDF.

## 🛠️ البنية التقنية (Tech Stack)

- **لغة البرمجة:** Kotlin
- **واجهة المستخدم:** Jetpack Compose + Material Design 3 (M3)
- **النمط المعماري:** Clean Architecture + MVVM + Unidirectional Data Flow (UDF)
- **قواعد البيانات:**
  - Firebase Firestore (للمزامنة السحابية والحسابات المشتركة)
  - SQLite / SharedPreferences (للوضع المحلي المستقل)
- **الأمان والتحقق:** Google Credential Manager API
- **الطباعة الرسومية:** Bitmap Canvas ESC/POS Raster Generator
- **الاختبارات الآلية:** JUnit 4 + Robolectric Unit Tests

## 🚀 التشغيل والبناء (Build & Run)

### متطلبات التشغيل:
- نظام تشغيل: Windows أو macOS أو Linux
- **Android Studio Ladybug (أو أحدث)**
- **Java JDK 21 أو 17**
- الحد الأدنى لإصدار أندرويد: Android 8.0 (API 26+)

### خطوات التشغيل:
1. استنساخ المستودع (Clone):
   ```bash
   git clone https://github.com/your-username/warehouse-ledger.git
   cd warehouse-ledger
   ```
2. فتح المشروع داخل **Android Studio**.
3. بناء نسخة التجربة (Debug APK):
   ```bash
   gradle assembleDebug
   ```
4. تشغيل الاختبارات الآلية (Unit Tests):
   ```bash
   gradle testDebugUnitTest
   ```

## 🔄 سير العمل الآلي (GitHub Actions CI/CD)

يحتوي المستودع على ملفات سير العمل الآلية داخل مجلد `.github/workflows/`:
1. **`android-ci.yml`**:
   - يعمل تلقائياً عند أي `push` أو `pull_request`.
   - يقوم بتثبيت JDK 21 وبيئة Gradle.
   - ينفذ كافة الاختبارات الآلية (`testDebugUnitTest`).
   - يقوم ببناء ملف التطبيق `app-debug.apk` ورفعه كـ Artifact جاهز للتنزيل المباشر.
2. **`release.yml`**:
   - يعمل عند إنشاء Tag جديد (مثل `v1.0.0`).
   - يقوم ببناء التطبيق وإنشاء GitHub Release رسمي مرفقاً به ملف الـ APK.
